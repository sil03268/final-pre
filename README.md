# 주식 HTML 아카이브 분석

교수님 아카이브(`/mnt/data/stock/날짜/종목코드.html`)를 읽어 정제하고 범위를 확인합니다.

## 실행 순서
1. `parse_archive.py`의 `ROOT`를 자료 경로로 맞춥니다.
2. `python3 read_all.py` : 전체 HTML을 읽어 `all.csv`, `failed.csv` 생성 (약 30분, 8프로세스)
3. `python3 scope.py` : 범위·결측 그림 생성
4. `python3 agg.py` : 날짜별·종목별 집계 파일 생성

## 결과 (2024-03-27 ~ 2026-09-02)
- 2,403,074개 파일, 5,760종목, 591거래일, 읽기 실패 0건
- 평일 45일은 폴더 없음(대부분 공휴일)
- 업종·시총 결측 약 34%(ETF 등), 종목명 결측 70%

## 자료 결함 처리
- 상장폐지·신규상장: 삭제하지 않고 존재한 기간만 사용
- 업종 재분류: 해당 날짜의 업종으로 집계
- 액면분할 의심: 주가 대신 시총 기반 수익률 사용
- ETF 등 업종 없는 종목: 업종 분석에서 제외

`all.csv`는 용량 때문에 올리지 않았습니다. 2번으로 생성하세요.
